# 🎬 Netflix Clone

A cinematic streaming interface built to practice layout precision, advanced navigation, and modern UI design principles.

## 📌 Project Overview
This project is a personal take on the Netflix web interface. My main focus was on getting the "feel" of a real streaming platform right—meaning smooth transitions, pixel-perfect spacing, and a clean, cinematic aesthetic that stays true to the original.

## 🛠 Tech Stack
- **Frontend:** React 19 (Functional Components & Hooks)
- **Build Tool:** Vite (For a lightning-fast dev experience)
- **Routing:** React Router v7 (Handling all the page navigation)
- **Styling:** Custom CSS (Focused on optical spacing and dark-mode vibes)

## ✨ Key Features
- **Smooth Navigation:** Switching between Home, Movies, and My List without any annoying page refreshes.
- **Layout Precision:** Spent a lot of time on the details to make sure everything lines up perfectly.

## 📦 Setup & Installation

3. Run `npm run dev` to start the development server.
